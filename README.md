## Selected Projects

- **[th06ds / NDS_TH06](https://github.com/jeong-jimin-github/NDS_TH06)** — Nintendo DS port of Touhou 06 targeting real DS hardware, including fixed-point math, custom asset conversion, rendering, audio streaming, and touch UI.
- **[PulseGrid MIDI Studio](https://github.com/jeong-jimin-github/MidiEditor)** — Windows MIDI editor with piano roll, drum sequencer, multitrack editing, SoundFont playback, and automated releases.
- **[NovelAI Batch Generator](https://github.com/jeong-jimin-github/novelaigen)** — Python utility for batch image generation from structured prompt data.
- **[dummy-openai-api](https://github.com/jeong-jimin-github/dummy-openai-api)** — Experimental OpenAI-compatible API server.
- **[Stable-Diffusion-Android](https://github.com/jeong-jimin-github/Stable-Diffusion-Android)** — Android-side experiments around Stable Diffusion image generation.
